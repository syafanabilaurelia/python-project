# Scientific Calculator GUI (Python)

Aplikasi kalkulator saintifik berbasis Desktop GUI dengan tampilan modern menggunakan **CustomTkinter** dan menerapkan konsep **Object-Oriented Programming (OOP)**.

## Fitur Utama
- Operasi matematika dasar (+, -, ×, ÷)
- Fungsi saintifik: Trigonometri (`sin`, `cos`, `tan`), Akar Kuadrat (`sqrt`), dan Pangkat (`^`)
- Antarmuka modern dengan *Dark Mode* dan skema warna kustom.
