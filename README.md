# Sistem Manajemen Inventaris Barang (Python & SQLite)

Aplikasi berbasis Command Line Interface (CLI) sederhana untuk mengelola data inventaris toko atau barang secara lokal. Proyek ini dibuat untuk mensimulasikan operasi dasar **CRUD** (*Create, Read, Update, Delete*) menggunakan basis data relasional SQLite.

---

##  Fitur Utama

- **[C]reate — Tambah Barang:** Memasukkan nama barang, jumlah stok, dan harga unit baru ke dalam basis data.
- **[R]ead — Lihat Daftar Barang:** Menampilkan seluruh data inventaris yang tersimpan secara rapi.
- **[U]pdate — Ubah Data Barang:** Memperbarui informasi nama, stok, atau harga barang berdasarkan ID unik.
- **[D]elete — Hapus Barang:** Menghapus data barang tertentu dari basis data dengan fitur konfirmasi pembatalan.


## Tech Stack

- **Bahasa Pemrograman:** Python 3
- **Database:** SQLite3 *(Bawaan Python, tanpa perlu setup server tambahan)*
- **Antarmuka:** Command Line Interface (CLI)
